## How this skill applies the practice

- Fixes one shape per work product, so outputs can be diffed and traced across runs and authors.
- Decides up front which work products a team keeps and where they live, instead of letting each skill invent a location.
- Keeps the attribute set small by default and extensible through `schema.json`.

## What this skill deliberately leaves out

- Choosing which work products a specific team needs: `re-setup`.
- Designing audience views and extra attributes: `attribute-schema`.
