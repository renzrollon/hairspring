# Return process notes

Arjun Pillai (SH-02, store operations lead), interview I-02, 2026-10-30:
- At the till the cashier scans the receipt and processes the return.
- The refund to the customer must not wait for loyalty; the POS sends the return to the loyalty service in the background.

Daniel Ng (SH-06, customer support lead), 2026-10-31:
- If loyalty can't match the return to a points transaction, it lands in our review queue.
- An agent looks up the member and the purchase. If it wasn't a loyalty purchase, the agent closes the case.
- Otherwise the agent enters a points adjustment with a reason code. Above 5,000 points a second agent must approve.

Open from the programme team: what happens when the points were already redeemed? Nobody has decided.
