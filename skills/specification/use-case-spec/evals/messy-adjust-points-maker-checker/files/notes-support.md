# Notes from Daniel Ng (SH-06, customer support lead), 2026-10-31

- Agents open the member in the admin console, hit the big red "Adjust" button and type the points (plus or minus).
- A reason code is mandatory; there is a dropdown with the codes.
- Anything above 5,000 points needs a second agent to approve it (maker-checker). The approver sees it in the "Approve" tab, sometimes hours later.
- If the approver says no, the first agent gets it back with a comment.
- It would be great if we could also export all adjustments to Excel every month.
- The member should see the adjustment in their history in the app.
