# LOY-231 Support adjusts points

Reporter: Daniel Ng (SH-06), 2026-10-30. Source: S-03 (support ticket export).

Support agents need to add or remove points for a member when a purchase was not recorded, always with a reason code. Adjustments above 5,000 points need a second approver (maker-checker). The adjustment screen must be user-friendly. Agents should also be able to see every adjustment ever made for a member.

Acceptance criteria from the ticket:
- Agent can adjust points.
- The screen is user-friendly.
- Big adjustments need approval.
