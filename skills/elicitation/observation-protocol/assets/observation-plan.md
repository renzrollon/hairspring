## Debrief script

Same day, <duration or TBD>, with each observed person.

1. "I saw you <do X> when <Y happened>. Can you tell me about that?"
2. "What would happen if you didn't do that?"
3. "How often does that happen in a normal shift or week?"
4. "If this worked the way you want, what would be different?"
5. "Was today a normal day? What usually happens that didn't today?"
6. "Did you do anything differently because I was watching?"
