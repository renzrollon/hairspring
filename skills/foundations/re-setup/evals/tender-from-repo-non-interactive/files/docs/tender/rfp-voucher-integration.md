# RFP LOY-2027-01: POS voucher integration

1. Harbourline invites vendors to build the voucher redemption integration between the TillPoint POS and the loyalty-points service at a fixed price.
2. The vendor shall implement against the requirements specification in Annex B, signed by both parties before development starts.
3. Changes to Annex B after signature require a change request approved by the steering committee: Harbourline Procurement, the Head of Loyalty (Mei Tan) and the vendor's project manager.
4. Harbourline runs acceptance tests against Annex B; the result decides the final payment.
