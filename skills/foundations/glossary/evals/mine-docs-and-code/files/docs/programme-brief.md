# Harbourline Rewards: programme brief

Harbourline Rewards lets a member earn points on every purchase at a Harbourline store or in the app.
Members see their points balance in the customer mobile app.
Points stay pending until the return window ends; then they are posted.
A member can redeem posted points for a voucher and apply the voucher at checkout.
Support agents can make an adjustment to a member's points in the admin console.
Bonus campaigns, run by Marketing, multiply the points earned on a purchase.
